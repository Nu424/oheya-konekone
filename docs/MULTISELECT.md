# 複数選択（設計メモ）

> 実験自動化装置のレイアウト版（tsubame-layout-designer）で設計・実装し、このリポジトリへ持ち込んだ仕組み。
> 文中の例（架台・プレート・ラック・ロボット）は装置版のまま残してある。部屋版では「デスク → モニター」「本棚の段 → 小物」と読み替えてほしい。
> この部屋版での扱いは「6. この部屋版での扱い」の節にまとめた。

複数のアイテムを同時に選び、まとめて移動・回転・コピー＆ペースト・削除・整列・パラメータ変更をする仕組み。

前提になる仕組み：積み重ね（[STACKING.md](STACKING.md)）、コピー＆ペースト（[CLIPBOARD.md](CLIPBOARD.md)）。

## 1. 何のためのものか

- 以前は選択が 1 個だけだった（`useUi.selection = { kind: 'item', id }`）。
- 「載っているものは一緒に動く」ので、架台 1 台ぶんのまとまりは 1 個の選択で運べる。
- 足りなかったのは、**載る・載せるの関係にないものをまとめて扱うこと**。
  - 天板の上に並んだラック 4 個を、まとめて 50 mm ずらす
  - 架台 2 台（とその上の全部）を、並びを保ったまま動かす
  - ラック 3 個の穴数を一度に変える
  - 横一列にそろえる、等間隔に並べる

## 2. 方針

1. **選択は「id の並び」で持つ。** 最後に選んだものを「主」とする。
2. **操作の対象は「選んだもののうち、ほかの選択に載っていないもの」（根）と、それに載っているもの。** 架台とその上のラックを両方選んでも、ラックは架台と一緒に 1 回だけ動く。
3. **まとめて動かすときは、形を保ったまま（剛体として）動かす。** 離したときに、それぞれが真下の面に着地する。
4. **1 回の操作は undo 1 回。**
5. **JSON は変えない。** 選択は画面の状態で、レイアウトには保存しない。グループという概念も足さない（積み重ねと複数選択で足りる）。

### グループ化を足さない理由

「選んだものをグループにして、以後 1 個として扱う」機能も検討した。足さない理由は次のとおり。

- JSON に親子や所属を持たせることになり、「平らで絶対座標」という方針（STACKING.md）から外れる。
- 架台やプレートに載せれば、それが実質的なグループになる。載せられないもの同士をまとめたい場面は、複数選択で足りる。
- 必要になったら、複数選択の上に「選択の組を名前を付けて覚える」機能として足せる（JSON の `meta` に id の配列を置くだけで済む）。

## 3. 選び方

| 操作 | 動き |
|---|---|
| クリック | そのアイテムだけを選ぶ（いまと同じ） |
| `Shift`+クリック / `Ctrl`+クリック | 選択に足す。すでに選ばれていれば外す |
| `Shift`+何もない所からドラッグ | 四角で囲んで選ぶ（範囲選択） |
| `Ctrl+A` | 全部選ぶ |
| 何もない所をクリック / `Esc` | 選択を外す |
| 選択中のアイテムをクリック（修飾キーなし、ドラッグなし） | そのアイテムだけの選択に戻す |

### 範囲選択に `Shift` を使う理由

何もない所からの素のドラッグは、いまカメラの回転（真上ビューでは平行移動）に使っている。これを範囲選択に変えると、視点を動かすたびにモードを切り替えることになる。
`Shift`+ドラッグなら、どのビューでも同じ操作で、既存のカメラ操作と衝突しない。`Shift`+クリックで足す操作とも覚え方がそろう。

### 範囲選択の当たり方

- アイテムの本体の箱（`body`）の 8 つの角を画面に投影し、その外接する四角を作る。
- **右へドラッグしたら「完全に囲んだもの」（実線の四角）、左へドラッグしたら「少しでもかかったもの」（破線の四角）**（CAD でよくある決まり）。
- 範囲選択は、いまの選択に足す（`Shift` を押しているので）。
- 載っているものまで囲んだ場合、選択には両方入るが、操作の対象は根だけになる（2 章の 2）。
- ロックされたアイテムは選べるが、動かない。

### 選択の見せ方

- 選んだものすべてに枠を出す。主だけ線を太くする。
- 2 個以上なら、全体を囲む破線の枠と、その上にツールバー（「3 点」＋回転・複製・ロック・削除）。
- 右のパネルは「3 点を選択中」という見出しと、選んだものの一覧（クリックで主にする、× で外す）。
- ロボットの到達範囲は、選んだロボットすべてに出す。

## 4. まとめて行う操作

| 操作 | 複数選択での動き |
|---|---|
| ドラッグで移動 | つかんだアイテム（先導）が、いまと同じように面を選び、吸い付く。ほかの根は同じ量（x・y・z）だけ動く。離したとき、先導以外の根はそれぞれ真下の面に着地する |
| 矢印キー | すべての根を同じ量だけ動かす |
| 回転（`R`） | **全体の中心を軸に回す**。それぞれの位置が回り、向きも同じだけ回る |
| 複製（`Ctrl+D`） | 並びを保ったまま、全体の幅＋すき間だけ横に複製する |
| コピー・切り取り・貼り付け | 主を基準にして、並びごと運ぶ。貼り付け先では主がマウスの下の面に載り、ほかは同じ並びで置かれて着地する |
| 削除 | 選んだものを消す。選んでいない「載っていたもの」は、下の面に落ちる（いまと同じ） |
| ロック | 全部ロック／全部解除（1 個でも未ロックがあれば、全部ロックする） |
| パラメータ | **同じ種類だけを選んでいるとき**に編集できる。値がそろっていない項目は「混在」と表示し、変えると全部に入る |
| そろえる・並べる | 左・中央・右、奥・中央・手前にそろえる。等間隔に並べる（3 個以上）。複数選択のときだけ出る |

### 着地の決まり

まとめて動かしたあと、先導以外の根は次のように高さを決める。

- 動かしたあとの高さ以下で、真下にある一番高い面に載る（なければ床）。
- 上には上がらない。動かした先で、ほかのアイテムの中にめり込む形になった場合は、ふだんどおり赤枠で知らせる（undo で戻せる）。

これで、「天板の上のラック 4 個を床の上へ」も「床の架台 2 台を別の場所へ」も、同じ決まりで動く。
天板の端からはみ出した 1 個だけが床に落ちる、ということは起きる。それは見たとおりの結果なので、そのままにする（undo で戻せる）。

### 回転の軸を「全体の中心」にする理由

それぞれがその場で回る案もある。まとめて選ぶのは「この並びごと向きを変えたい」ときなので、全体の中心で回すほうが期待に合う。
その場で回したいときは 1 個ずつ選べばよい。軸は、根の本体の箱を合わせた外接箱の中心（上から見た位置）。

### パラメータ編集の範囲

- **同じ種類だけ**：パラメータの定義が同じなので、いまのパネルをそのまま使える。変更は、選んだ 1 個ずつに `itemCommands.setParams` を呼ぶ（載っているものの高さ追従もそのまま効く）。実装は小さい。
- **種類が混ざっているとき**：共通の項目（色など）だけを出す案もあるが、キーが同じでも意味が違うことがあるので、最初は出さない。位置・回転・そろえる・並べる、だけにする。

## 5. 実装

### 状態（`src/store/useStore.ts`）

```ts
interface UiState {
  /** Selected item ids in the order they were picked; the last one is the primary. */
  selection: string[]
  select(ids: string[] | string | null, mode?: 'replace' | 'toggle' | 'add'): void
}
```

- いまの `{ kind: 'item', id } | { kind: 'opening', id } | null` を置き換える（`opening` はもう使っていない）。
- 主は `selection.at(-1)`。「1 個だけ選んでいる」かどうかは `selection.length === 1`。
- レイアウトが変わって id がなくなったら、選択から外す（undo・JSON 読み込み・削除のあと）。

### 対象の決め方（`src/editor/stacking.ts` に足す）

```ts
/** Selected ids that do not ride on another selected item: the things an operation acts on. */
roots(layout, ids): string[]
/** Rigidly move the roots (with their riders) by a delta. */
moveGroup(layout, ids, delta: { x, y, z }): Map<string, Pose>
/** Turn the roots around a pivot. */
rotateGroup(layout, ids, pivot: { x, z }, degrees): Map<string, Pose>
/** Let each root (except `leadId`) come to rest on what is below it. */
landGroup(layout, ids, leadId?): Map<string, Pose>
```

どれも、いまの `supports` / `riders` / `moveWithRiders` / `surfaceUnder` の組み合わせで書ける。

### ドラッグ中のつかみ方

- 複数選択の中のアイテムをつかむと、選択全体が動く。先導は、つかんだアイテム（それが選択中の別のアイテムに載っているなら、その載せているほう）。
- 選択に入っていないアイテムをつかむと、そのアイテムだけの選択に切り替わって動く（いままでどおり）。
- ロックされたアイテムは、選択に入っていても動かない。
- 修飾キーなしで、動かさずに離した（クリックした）ときは、そのアイテムだけの選択に戻す。

### 落とせない場所

まとめて動かすと「指した先がどこか」のあいまいさが目立つので、あわせて直した（1 個のドラッグ、カタログからのドロップ、貼り付けにも効く）。

- **ほかのアイテムの中**には置かない（架台の天板の下にもぐる、など）。
- **ほかのアイテムの陰になっている場所**には置かない。架台の前面を指したとき、視線は架台を突き抜けて裏の床に届くが、そこには置かない。
- 陰を作るのは「上に物を載せられるアイテム」（架台・デッキ・冷蔵庫・かさ上げ台など）だけ。ラックやロボットは陰を作らない（ラックの向こうの天板には、そのまま置ける）。
- 自分自身の面は、自分の体に隠されない（冷蔵庫の庫内の棚、作業台の中段には置ける）。
- 置ける場所がないときは、アイテムは最後に置けた場所にとどまる。

実装は `stacking.ts` の `pickAlongRay` の `solids` オプションと、`placement.ts` の `solids()`。

### 入れた順番（移植するときも同じ順がよい）

1. **選択の持ち方と見せ方**：配列化、`Shift`/`Ctrl`+クリック、枠、右パネルの一覧。ここまでで、1 個選択の操作が壊れていないことを確かめる。
2. **まとめて動かす**：ドラッグ・矢印キー・回転・削除・複製・ロック。
3. **コピー＆ペースト**：複数の根に対応。
4. **範囲選択**：`Shift`+ドラッグ、`Ctrl+A`。
5. **同じ種類のパラメータ編集、そろえる・並べる。**

### テスト

`src/__tests__/stacking.test.ts` と `src/__tests__/clipboard.test.ts` にある。

- `roots`：架台と、その上のラックを両方選ぶと、根は架台だけになる。
- `moveGroup` ＋ `landGroup`：天板の上の 2 個を床の上へ動かすと、どちらも y = 0 になり、並びが保たれる。低い架台の上へ動かすと、その天板に載る。先導は着地の対象から外れる。
- `rotateGroup`：2 個を 90° 回すと、中心からの位置が入れ替わり、向きも 90° 変わる。
- コピペ：載る関係にない 2 個（とその上の物）をコピーして貼ると、間隔が保たれ、貼ったあとの根が形から正しく求まる。
- 落とせない場所：架台の前面を指しても裏の床に落ちない。架台の手前の床と、架台の中の棚には置ける。

そろえる・並べる、同じ種類のパラメータ編集、範囲選択の当たり判定は、画面での確認だけで、自動テストはまだない。

## 6. この部屋版での扱い

- 選択は `useUi.selection: string[]`（最後が主）。元の作りにあった「開口部の選択」はどこでも使っていなかったので、そのまま無くした。
- 範囲選択は `Shift`+ドラッグ。素のドラッグはカメラ操作のまま。
- 椅子を机の下に入れた組（`tucks`）は、まとめて選べば一緒に動く。特別な扱いはしていない。
- 「全体表示」（`F` キー）は入れていない。部屋版の `F` は動線チェックで、カメラは部屋が基準のため。

## 7. 割り切りと、あとで足せるもの

- **吸い付きは先導のアイテムだけ**で行う。全体の外形で吸い付かせることはしていない。
- **着地は下方向だけ。** まとめて動かした先で、先導以外が別のアイテムにめり込むことがある（赤枠で知らせる）。
- **寸法の違う面にまたがる着地**は、それぞれが真下に着地するだけで、並びの高さはそろえない。
- **種類が混ざった選択のパラメータ編集**はしない。
- あとで足せるもの：配列複製（縦 N × 横 M、ピッチ指定で並べる）、選択の組に名前を付けて覚える、全体の外形での吸い付き、選んだものだけの寸法表示。
