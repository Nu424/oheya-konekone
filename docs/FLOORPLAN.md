# 間取り（区画と壁）

部屋まるごと（玄関・廊下・キッチン・ユニットバス・トイレ・洋室）を作れるようにするための設計と計画。
派生アプリ（装置レイアウト版）にも入れる前提で、仕組みと移植の手順もここにまとめる。

## 1. 決めたこと

- **区画（space）が主役、壁はその境目から自動で作る。** 壁を家具として置く案は取らない（ドアや壁付けの物が「どの壁か」を持てない、部屋ごとの床が持てない、壁の切り取り表示と動線が作り直しになる）。
- **区画は長方形。形は直角の組み合わせだけ。** 斜めの壁はいまはやらない。日本の賃貸の間取りはほぼこれで描ける。
- **区画は辺で接する。** 接している辺は内壁（厚さ `interiorWallThickness`、境目の線の両側に半分ずつ）、どこにも接していない辺は外壁（いまと同じく外側に `wallThickness`）。
- **いまの `room`（幅×奥行きの長方形 1 つ）は「区画が 1 つの間取り」として読む。** `spaces` を書かなければ何も変わらない。古い JSON・テンプレート・AI のルールはそのまま通る。
- **天井高は家全体で 1 つ**（`room.height`）。区画ごとの天井高・床の段差は後で足せる形にしておく。
- `room.width` / `room.depth` は **全体を囲む長方形（外形）** の意味になる。区画はその中に置く。カメラの向け方・図面の寸法・影の範囲など、外形で足りる処理はそのまま使う。

## 2. JSON

```jsonc
"room": {
  "width": 5400, "depth": 4200, "height": 2400,
  "interiorWallThickness": 100,
  "spaces": [
    { "id": "main",   "name": "洋室",     "rect": [0, 0, 3600, 2700] },
    { "id": "hall",   "name": "キッチン", "rect": [0, 2700, 3600, 1500], "floor": { "material": "tile" } },
    { "id": "bath",   "name": "浴室",     "rect": [3600, 0, 1800, 1600], "floor": { "material": "tile" } }
  ],
  "openings": [
    { "id": "d1", "type": "door", "space": "main", "wall": "south", "offset": 2600, "width": 700 },
    { "id": "w1", "type": "window", "space": "main", "wall": "north", "offset": 500, "width": 1700 }
  ]
}
```

- `rect` は `[x, z, 幅, 奥行き]`（北西の角と大きさ、mm）。内法ではなく、壁の中心線（外壁なら内側の面）で区切った大きさ。
- 開口部の `space` + `wall` + `offset` は「その区画のその辺の、座標が小さい端から」。`space` を省くと、いままでどおり外形の辺からの距離。
- ドアの `swing: "in"` と `hinge` は `space` に書いた区画の内側から見たもの。内壁のドアは、どちらの区画から書いてもよい。
- 区画ごとの `floor` を省くと `room.floor`。

## 3. 内部の形

`src/model/plan.ts` が間取りから次のものを作る。ほかの処理はこれだけを見る（`room.width` / `depth` で壁を決めつけない）。

| 名前 | 中身 | 使うところ |
|---|---|---|
| `spacesOf(room)` | 区画の一覧（`spaces` がなければ外形 1 つ） | 床、動線、はみ出しの判定 |
| `faces` | 区画の各辺の「壁の内側の面」。内壁は両側に 1 つずつ。辺の一部だけが接していれば分けて持つ | 吸い付き、いちばん近い壁、壁付けの物、開口部の位置 |
| `walls` | 描く壁。外壁は面ごと、内壁は 2 つの面に対して 1 つ。角を閉じるための延長つき | `RoomMesh`、図面、壁の切り取り表示 |
| `resolveOpening(room, o)` | 開口部がどの面のどこにあるか（絶対座標の範囲）、どの壁に穴をあけるか | 壁の生成、動線、照明、検証 |
| `usableRects(room)` | 区画から内壁の厚さの半分を引いた、家具を置ける範囲 | はみ出しの判定、新しい物を置く場所 |

## 5.1 その後に足したこと

- **壁の表示は 5 段階の切り替え**（`H`、HUD の「壁：…」、`src/three/wallDisplay.ts`）：全部 → 手前の外壁を低く → 外壁だけ（内壁を低く）→ 奥の外壁だけ（はじめはこれ）→ 全部低く。表示される壁が多い順。「手前」は、カメラが壁の外側にいる外壁。真上の視点はいつも全部低く、歩くモードはいつも立てる。
- **区画ごとの壁の仕上げ**（`spaces[].wall`：`color` と `finish` = 壁紙 / 化粧パネル / タイル）。内壁は厚さの半分ずつ、両側の区画の仕上げで作る。
- **区画ごとの床の高さ**（`spaces[].floorLevel`、玄関の土間は -150）。
  - 床の高さは `floorAt(room, x, z)`。積み重ねの仕組みは `StackingHost.floorAt` / `floorLevels` を通して床の高さを知る（落とす・置き場所・宙に浮いている判定・レイで床を拾う）。
  - 壁は一番低い床まで下に伸ばす。ドアや通り抜けの下は、低い床までの「段（上がり框）」になる。
  - パネルで床の高さを変えると、その区画の中の家具も一緒に上下する（`setSpaceLevel`）。
- **歩くモード**は FPS 風（`src/three/WalkRig.tsx`）：クリックでマウスを画面に固定、`WASD`・`Shift`、`Esc` で離す。当たり判定は `src/editor/walk.ts`（壁・柱・ひざ〜頭の高さの家具。ドアと通り抜けは通れる）。下のバーで当たり判定のオンオフ・身長・速さ・感度・全画面・入口へ。

## 6. 残っていること・気づいたこと

- 区画の辺を動かしても、中の家具は動かない（壁にめり込んだら重なりの赤枠で知らせる）。「区画と一緒に家具も動かす」はまだ。
- 壁を切り取って見せるとき、内壁は正面を向いているものが低くなる。浴槽の水栓やシャワーのように壁に付く部品は、壁が低くなると宙に浮いて見える。
- 天井は外形の長方形 1 枚。区画ごとの天井高はまだ。
- 歩くモードで床の段差を歩くと、目の高さがそのまま段の分だけ上下する（なめらかにはしていない）。
- 開口部の「どの壁？」は区画の辺で選ぶ。内壁のドアは 2 つの区画が接している範囲に置かないと警告が出る。
