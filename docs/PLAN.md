# おへやこねこね 計画書

一人暮らしサイズの部屋を3Dでデザインして遊べるWebアプリ。家具はパラメトリック、配置はJSONで入出力でき、AIエージェントにも配置を考えてもらえる。

## 決定事項
| 項目 | 決定 |
|---|---|
| 描画 | WebGL2（リアルタイム編集）＋撮影モード（パストレーシング） |
| 部屋の形 | 長方形＋開口部（ドア・窓・クローゼット）＋柱。ミニキッチン・エアコンなどの備え付け設備は `locked` 付きのアイテムとして置く。スキーマは将来多角形に広げられる形にする |
| デバイス | PC優先。スマホは閲覧と軽い操作 |
| 公開 | GitHub Pages（Actionsで自動デプロイ）。保存は localStorage と JSON ファイル。サーバーなし |

## 技術スタック
- Vite + React + TypeScript
- three.js / @react-three/fiber / @react-three/drei
- @react-three/postprocessing（N8AO、SMAA など）、three-gpu-pathtracer（撮影モード）
- Zustand + zundo（undo/redo）
- zod（スキーマ定義と検証）→ zod-to-json-schema（AIに渡すJSON Schemaの生成）
- Playwright（アセットギャラリーのスクショを撮って目視確認・回帰チェック）

## 座標系と単位
- 単位は mm、角度は度
- 原点は部屋の左奥の床の角。X = 幅方向、Z = 奥行き方向、Y = 上
- 壁の名前は north（奥）/ south（手前）/ west（左）/ east（右）

## レンダリング
- MeshPhysicalMaterial、AgXトーンマッピング、HDRI環境光（RoomEnvironment など同梱で済むもの）
- 柔らかい影（PCSS系 / AccumulativeShadows）、N8AO で接地感を出す
- 木目・布・金属は手続き的なテクスチャ（ノイズ）＋色パラメータで表現する。外部のテクスチャ素材に依存しない
- 時間帯スライダー：太陽光の向きと色温度、室内照明のON/OFF
- 撮影モード：three-gpu-pathtracer でサンプルを積み上げて、PNGとして書き出す

## データモデル（JSON）
```jsonc
{
  "version": 1,
  "meta": { "name": "はじめての1K" },
  "room": {
    "width": 3600, "depth": 2700, "height": 2400,
    "floor": { "material": "oak", "color": "#b98a5e" },
    "wall": { "color": "#f4f1ea" },
    "openings": [
      { "id": "win-1", "type": "window", "wall": "south", "offset": 900, "width": 1700, "height": 1800, "sill": 0 },
      { "id": "door-1", "type": "door", "wall": "north", "offset": 200, "width": 780, "height": 2000, "hinge": "left", "swing": "in" }
    ],
    "columns": [ { "id": "col", "x": 3700, "z": 200, "width": 400, "depth": 400 } ]
  },
  "items": [
    { "id": "bed-1", "type": "bed", "position": [200, 0, 300], "rotation": 90,
      "params": { "size": "semi-double", "legHeight": 250, "frameColor": "#8a6a4f", "beddingColor": "#c9d6df" } }
  ]
}
```
- `position` はアイテムの底面中心（X, Y, Z）。Y は棚の上などに置くときに使う
- `params` は省略したら各アセットのデフォルト値。範囲外の値は検証エラーとして、場所と理由を返す
- 保存方法：ファイル保存・読み込み、クリップボード、ドラッグ＆ドロップ、localStorage への自動保存

## アセット
各アセットは次の3つを持つ。
- `schema`：zod で書いたパラメータ定義（型・範囲・デフォルト・UI用のラベル）
- `build(params)`：パラメータから three.js のグループを作る関数
- `presets`：パラメータの組み合わせに名前をつけたもの（例：「シングル・脚つき」）

UIのパラメータパネル、AI向けのアイテム一覧、カタログのサムネイルは、すべてこの定義から自動で作る。

| カテゴリ | アイテム |
|---|---|
| 寝具 | ベッド（シングル/セミダブル/ダブル、脚の高さ、ヘッドボード、下の収納）、敷布団 |
| くつろぎ | ソファ（1〜3人掛け）、座椅子、ビーズクッション |
| テーブル | ローテーブル、こたつ、ダイニングテーブル、ダイニングチェア |
| 作業 | デスク（I字/L字）、オフィスチェア、モニター |
| 収納 | 本棚、カラーボックス、チェスト、ハンガーラック |
| AV | テレビ台、テレビ |
| 家電 | 冷蔵庫、洗濯機、電子レンジ＋レンジ台 |
| 雑貨 | ラグ、カーテン、観葉植物、ペンダントライト、フロアランプ、姿見、ゴミ箱 |
| 部屋側 | ドア、腰窓、掃き出し窓、クローゼット、柱 |
| 備え付け（locked アイテム） | ミニキッチン、エアコン |

確認方法：`/gallery` ページで各アセットをデフォルト・最小・最大のパラメータで並べ、Playwright でスクショを撮って目で見て直す。

## UI/UX
- 3Dビュー / 真上の2Dビュー / ウォークモード（目線1.5m）を切り替え
- ドラッグで移動。壁や家具への吸い付き、グリッドスナップ、回転は15°刻み（Shiftで自由に回す）
- 動かしている間は壁までの距離を表示。重なったら赤く表示
- 動線チェック：ドアの開く範囲、通路幅（600mm未満なら注意）、窓をふさいでいないか
- カタログ：実際のモデルから描いたサムネイル、プリセット、検索
- 選択中のアイテムのパラメータパネル（スキーマから自動生成）、複製、削除、元に戻す・やり直す
- 部屋のテンプレート（6畳1K、8畳ワンルーム、縦長1Kなど）
- 畳数の表示、置いたときの小さなアニメーション
- 「AIに頼む」：スキーマ、アイテム一覧、今の配置、ルールをまとめたプロンプトをコピー → AIが返したJSONを貼り付け → 検証し、差分をプレビューしてから反映
- ショートカット：R 回転 / Del 削除 / Ctrl+D 複製 / Ctrl+Z 元に戻す / Ctrl+Shift+Z やり直す / 1・2・3 ビュー切り替え

## フェーズ
1. **P0 土台**：Vite の雛形、描画パイプライン、部屋の生成（壁・床・天井・開口部）、JSONスキーマと読み込み・書き出し、Pages へのデプロイ設定
2. **P1 アセット**：アセット定義の仕組み、マテリアルライブラリ、ギャラリー、全アセットの作成と目視チェック
3. **P2 編集操作**：選択、ドラッグ、スナップ、当たり判定、パラメータパネル、undo、2Dビュー
4. **P3 気の利く機能**：動線チェック、AI連携、テンプレート、時間帯
5. **P4 仕上げ**：撮影モード、ウォークモード、アニメーション、パフォーマンス調整、スマホでの閲覧

各フェーズの終わりにコミット＆プッシュして、スクショで進捗を共有する。
