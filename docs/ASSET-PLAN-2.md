# アセット拡充の計画（第 2 弾）

2026-10 の依頼：壁の飾り・壁付け収納、キッチン小物、ロフトベッド、吊り干し、間仕切りカーテン、ゲーム機・スピーカー。
あわせて「空中にある家具（下をくぐれる・下に物を置ける）」を基盤の仕組みとして用意する。
決めたことと進み具合はここに追記していく。

## 0. 方針

1. **既存のアセットのパラメータで表せるものは、既存の方を広げる。** 新しい種類を作るのは、置き方（床・壁・天井）や作りが根本から違うときだけ。
2. **基盤の拡張は派生アプリにも入れる。** 仕組みと移植の手順を [OVERHEAD.md](OVERHEAD.md) にまとめる。
3. いつもどおり、1 アセットずつギャラリーで最小・最大・各プリセット・入力の上限の端を目で確かめてから入れる。

## 1. 「空中にある家具」の仕組み（フェーズ A）

### 1.1 いまの仕組みで、すでにできていること

- 当たり判定（`overlaps3D`）は高さも見ている。壁付けのエアコンと、その下の机はぶつからない。
- 壁付け（`wall`）の物は `position.y` が取り付け高さ。天井付け（`ceiling`）の物は天井から下に伸びる。
- 動線は、下端が 1200mm より上にある物を障害物にしない。

### 1.2 足りないこと

| 例 | 足りないこと |
|---|---|
| ロフトベッド | 当たり判定の本体が箱 1 つなので、脚のあいだの「下の空間」まで埋まってしまう。机を入れると重なりになり、床に落とせない場所にもなる |
| 壁掛け棚・吊り戸棚・天袋 | 壁付けの物には、上に物を置ける面を持たせられない（`itemSurfaces` が壁付けを除いている） |
| 天袋 | 取り付け高さが 1 つの数字（`elevation`）で、「天井にぴったり付ける」が言えない |
| 吊り干しの物干し | 天井付けの物は、いつも当たり判定から外れる（照明のため）。服が背の高い棚にかぶっても知らせられない |

### 1.3 決めたこと：新しい「置き方」は作らず、4 つの小さな拡張にする

浮いている物を新しい `placement` にすると、ドラッグ・貼り付け・AI のルールのすべてに分岐が増える。
「浮いている」の正体は「本体が床から離れた位置にある」「本体がいくつかの箱に分かれている」だけなので、そこを広げる。

1. **`solids`（本体を複数の箱で表す）**：`AssetDef.solids?(p): LocalBox[]`。ロフトベッドなら柱 4 本・床板・はしご。
   当たり判定・動線・床に落とせない場所はこの箱ごとに調べる。吸い付き・選択の枠は、いままでどおり全体の外形（`body`）を使う。
   `solids` を書いたら `body` は省略でき、そのときは箱を全部囲む外形になる。
2. **壁付けの物も面を持てる**：壁付けで `surfaces` を書いた物（壁掛け棚・吊り戸棚）は、上に物を置ける。上の物は棚と一緒に動く。
   書かなければ、いままでどおり何も置けない（エアコン・時計）。
3. **取り付け高さを「天井から」で決められる**：`elevation` に関数を渡せる（`(p, room) => mm`）。天袋は「天井高 − 本体の高さ」。
4. **天井付けの物も当たり判定に入れられる**：`AssetDef.blocks?: boolean`。天井付けは既定で当たり判定の外（照明）、`blocks: true` の物（吊り干し）だけ入る。
   ついでに、いまコードに直書きしている「ぶつからない物」（ラグ・カーテン・クッション）も `blocks: false` で表す。

## 2. アセット

| 内容 | 作り方 | 置き方 | 主なパラメータ・プリセット |
|---|---|---|---|
| ポスター・アートフレーム | 新規 `wallArt` | 壁 | 大きさ（A4〜B1・正方形・自由）、枠（なし＝テープ／クリップ、細い金属、木、太い木）、余白（マット）、絵柄（抽象図形・グラデーション・山の風景・植物の線画・文字・幾何学）、色の雰囲気、**枚数と並べ方**（1 枚／横並び／2×2 のギャラリー） |
| 壁掛け棚・吊り戸棚・天袋 | 新規 `wallStorage`（`storageKit` で組む） | 壁（面あり） | 形（1 枚板の棚／箱の棚／開き戸／引き戸／フラップ扉）、幅・高さ・奥行き、段数、列数、棚受け（見えない・アイアン）、素材・色。プリセット：ウォールシェルフ、飾り棚、吊り戸棚、天袋（天井ぴったり） |
| キッチンワゴン | **既存 `metalRack` を拡張** | 床 | 棚板に「かご（深いワイヤーの枠）」を追加、持ち手。プリセット「キッチンワゴン」 |
| 水切りかご | 新規 `dishRack` | 物の上 | 幅、段数（1／2 段）、材質（ステンレス／白い樹脂）、トレー、はし立て、食器の数 |
| コーヒーメーカー | 新規 `coffeeMaker` | 物の上 | 形（ドリップ＋ガラスポット／カプセル式／全自動）、色、ポットの有無 |
| ロフトベッド | 新規 `loftBed`（寝具の作りは `bed` と共通化） | 床（`solids`） | 床板の高さ（ミドル 800〜ハイ 1600）、幅・長さ、フレーム（スチールパイプ／木）、はしご（縦はしご／階段）とその位置、柵の高さ、寝具・色。プリセット：ハイ、ミドル、木製 |
| 吊り干しの物干し | 新規 `ceilingDryer` | 天井（`blocks`） | 竿の長さ、吊り下げの長さ、洗濯物の数と種類（シャツ・タオル・ピンチハンガー）、色。服の形は `hangerRack` と共通化 |
| 床置きの物干し | **既存 `hangerRack` のプリセット** | 床 | 「室内物干し」（洗濯物の見た目を選べるようにする） |
| 間仕切りカーテン | 新規 `roomDivider`（ひだの作りは `curtain` と共通化） | 天井 | 幅、丈（床まで／のれん丈）、開き具合と寄せる側（左／右／両側）、レール（天井レール／突っ張り棒）、生地（不透明／レース／柄）、色。プリセット：間仕切りカーテン、のれん、レース |
| ゲーム機 | 新規 `gameConsole` | 物の上 | 形（縦型の据え置き／横置きの箱／携帯機＋ドック）、向き（縦置き／横置き）、色、コントローラーの数 |
| スピーカー | 新規 `speaker` | 物の上 | 形（ブックシェルフのペア／サウンドバー／スマートスピーカー／床置きトールボーイ）、大きさ、ペアの間隔、本体・ネットの色 |

特定の製品やブランドには寄せない（ロゴ・形の特徴を真似しない）。
