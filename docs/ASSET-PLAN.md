# アセット追加・刷新の計画

2026-10 時点の依頼（新規アセット 8 種、既存アセットの分割、棚の統一、ブラッシュアップ）をまとめた計画書。
決めたことと進み具合はここに追記していく。

## 0. いまの状態と、のっぺり・丸い原因

ギャラリーで全アセットを見直した結果。

- **角の丸めが大きすぎる。** `rbox` が 64 か所で使われていて、半径 45〜220mm のものもある。家具の板の角は実物だと 1〜5mm。丸めで「やわらかいおもちゃ」っぽく見えている。
- **継ぎ目・すき間がない。** 扉と本体、引き出しどうしのあいだの 2〜3mm の溝がないので、1 個の塊に見える（チェスト、冷蔵庫、ドラム式洗濯機）。
- **厚みと奥行きの段差が少ない。** 前板が本体と同じ面にあり、影ができない。
- **細部の部品がない。** アジャスター、キャスター、ヒンジ、ネジ、ボタン、表示窓など。小さいけれど「本物らしさ」はここで決まる。
- **金属がほぼ 1 種類。** ステンレスのヘアライン、クロムめっき、粉体塗装（つや消しの白・黒・グレー）の区別がない。
- 個別の不具合：
  - 姿見のスタンド：脚が鏡の裏に隠れて見えず、鏡が支えなしで立っているように見える。
  - ゴミ箱：フタなしでも中が詰まっている。
  - ドラム式洗濯機：前面がのっぺりしている。

## 1. 進め方の原則

1. **先に道具を直す。** 角の丸め・継ぎ目・金属・扉・引き出し・キャスターを `kit.ts` と `materials.ts` の部品にする。各アセットはそれを組み合わせる。直す場所が 1 か所で済み、全体の質感がそろう。
2. **中に入れる物は「別のアセットを積み重ねる」のが基本。** 本・箱・家電は個別のアセットにして、棚には面だけを持たせる（くわしくは 4 章）。
3. **古い JSON はそのまま読めるようにする。** 種類の統合・分割は、読み込み時に新しい形へ自動で変換する（`io.ts` に `migrate`）。AI が古い種類名を書いても通る。
4. **1 アセットずつ、ギャラリーで目で確かめてから入れる。** 最小・最大・各プリセット・受け付ける範囲の端（`?gallery&limits=`）。必要なら実物の寸法を調べてから作る。

## 2. 共通の道具（フェーズ 0）

| 道具 | 中身 |
|---|---|
| `panel(w, h, d, { edge })` | 角を 1〜5mm だけ丸めた（または面取りした）板。`rbox` の大きな半径を置き換える標準の箱 |
| `gap` の約束 | 扉・引き出しの前板は本体より 2〜3mm 小さく、3〜5mm 手前に出す。溝の奥は暗い色の板で埋める |
| 取っ手の部品 | バー、つまみ、彫り込み（溝）、くぼみ、ロッカー用のレバー |
| 扉・引き出しの部品 | 開き戸（左右の吊り元、開く角度）、引き戸（前後 2 枚、どちらに寄せるか）、引き出し（引き出し量）、上開き・下開き |
| 足まわりの部品 | アジャスター、キャスター（ロック付き）、ポールの足、T 字脚、ブロック脚 |
| 金属の材質 | `stainless`（ヘアライン）、`chrome`（めっき）、`powder`（粉体塗装、つや消し）、`aluminum`。色見本は白・黒・グレー・ブロンズ |
| 印刷の部品 | 箱や本の表面に描く文字・ロゴ・帯（キャンバスで生成）。段ボールの「取扱注意」、お菓子の箱の柄、本の背表紙 |
| 穴あき・メッシュ | パンチングメタル、メッシュの背もたれ、ワイヤー棚の格子（テクスチャまたはインスタンス） |

全部パス トレーサーで壊れないこと（マテリアル配列を使わない）を守る。

## 3. 既存アセットの分割（フェーズ 1）

棚に入れる物になるので、棚より先に作る。

| 新しいアセット | 主なパラメータ | もとになるもの |
|---|---|---|
| `monitor`（作り直し） | サイズ（インチ）、比率（16:9 ／ ウルトラワイド）、**向き（横 ／ 縦）**、スタンド（標準 ／ アーム ／ なし）、画面（消灯 ／ 点灯・表示内容）、色 | `monitor` の枚数・ノート PC・キーボードは外す |
| `laptop` | サイズ（13〜16 インチ）、開く角度（閉じる〜135°）、色、画面 | `monitor` の laptop |
| `keyboardMouse` | キーボードの幅（テンキーあり・なし）、マウス、マウスパッド、色 | `monitor` の keyboard |
| `desktopPC` | 形（タワー ／ ミニタワー ／ 小型 PC）、ガラスの横板と光の色、色 | 新規 |
| `bookRow`（縦置きの本） | 列の幅、本の高さの範囲、色の雰囲気（カラフル ／ 落ち着き ／ 文庫 ／ 雑誌）、ブックエンド、最後の 1 冊を斜めに | 本棚の `books()` |
| `bookStack`（平積み） | 冊数、大きさ（文庫 ～ 大判）、ずれ具合 | 新規 |
| `documents`（書類） | 種類（紙の束 ／ クリアファイル ／ フラットファイル ／ バインダー）、量 | 新規 |
| `fileBox`（ファイルボックス） | 幅、高さ、材質（紙 ／ プラスチック）、色、中身の有無 | 本棚の飾り箱、カラーボックスのインナーボックス |
| `microwave` / `riceCooker` / `kettle` | 大きさ、色、扉や表示 | `rangeRack` の中身 |

**古い JSON の変換**：`monitor` の `count: 2` → モニター 2 台を横に並べた状態、`laptop: true` → `laptop` を隣に、`keyboard: true` → `keyboardMouse` を手前に。`rangeRack` の `microwave` などは、棚の中の面に家電のアイテムとして置き直す。

## 4. 棚の統一（フェーズ 2）

### 4.1 種類をいくつにするか

1 つの「棚」アセットに全部入れると、パラメータが 30 個近くになって、人も AI も選びにくい。
そこで、**作る道具（`storageKit`）を 1 つにして、カタログの種類は役割で 3 つに分ける**ことを勧める。

| 種類 | 役割 | プリセットの例 |
|---|---|---|
| `shelf`（オープン棚） | 扉のない棚。段数・列数・背板・天板の張り出し | 本棚、壁一面の本棚、カラーボックス（縦・横）、レンジ台、見せる収納、ロー ボード |
| `metalRack`（メタルラック） | ポールと棚板。アイリスオーヤマのような組み立てラック | 幅 55／75／91／122cm、棚板の種類（ワイヤー ／ 木目の板 ／ ガラス）、ポールの色、足（アジャスター ／ キャスター）、側面のバスケット |
| `cabinet`（扉・引き出し付き） | 上段と下段をそれぞれ「開き戸 ／ 引き戸 ／ ガラス引き戸 ／ 引き出し ／ 上開き ／ オープン」から選ぶ | チェスト、衣装ケース、ロッカー（縦 1 列 × N）、引き戸書庫、スチール書庫（上ガラス引き戸＋下開き戸）、食器棚 |

`cabinet` の主なパラメータ：

- 本体：幅・高さ・奥行き、材質（木 ／ スチール ／ 化粧板）、色
- 区切り：列数、上段の高さの割合
- 各段の扉：種類、**扉の分け方（マスごと ／ 横一列 ／ 縦一列 ／ 全面 1 枚）**、取っ手、**開き具合**（開くと中の面が見えて物を置ける）
- 引き出し：段数、取っ手

テレビ台も `cabinet` のプリセットに入れられる（いまの `tvStand` はそのまま残して、内部だけ `storageKit` に移す案もある）。

**古い種類の扱い**：`bookshelf` / `colorBox` / `rangeRack` → `shelf`、`chest` → `cabinet`。読み込み時に変換し、パラメータも対応させる。

### 4.2 中に入れる物：パラメータか、積み重ねか

**積み重ねを基本にする**ことを勧める。

| | パラメータで中身を指定 | 積み重ねで置く（勧める） |
|---|---|---|
| 自由度 | 決まった選択肢だけ | 何でも置ける。1 冊ずつ動かせる |
| AI が書くとき | 書きやすい | アイテムが増えるが、面の高さはカタログに出ている |
| 一貫性 | 棚ごとに中身の作りを持つことになる | 本や箱を 1 回作れば、机の上でも床でも使える |
| 当たり判定 | 中身は見た目だけ | 中身もちゃんと場所をとる |

**決定：積み重ねだけにする**（「おまかせで詰める」機能は作らない）。手間を減らすのは、`bookRow` のように「1 段ぶんをまとめて 1 アイテム」にしたアセットと、テンプレート・プリセットの側で受け持つ。
いまの `本を並べる` のようなパラメータは無くす。古い JSON を変換するときは、本が並んでいた段に `bookRow` を置いた状態にする。

### 4.3 置ける面のルール

- 段ごとの面は、いまの本棚と同じく「0 番が天板、続いて下の段から」。扉が閉じていても面はある。
- 扉を閉じた棚の中の物は外から見えないので、ドラッグで中の面を狙えないことがある（いまの陰の判定）。開き具合を上げれば置ける。

## 5. 新しいアセット（フェーズ 3）

カテゴリに **「オフィス」** と **「小物」** を足す。

| アセット | パラメータの案 |
|---|---|
| `officeDesk`（コクヨ S シリーズ風） | 幅 1000〜1800 ／ 奥行き 600・700 ／ 高さ 700〜720、**幕板（奥のパネル）**：なし ／ 半分 ／ 床まで、**袖**：なし ／ 左 ／ 右 ／ 両袖、袖の引き出し：2 段（A4 ファイル）／ 3 段、**センター引き出し**：あり ／ なし、脚の形（パネル ／ L 字 ／ T 字）、配線カバー、天板の縁（ソフトエッジ ／ 直角）、天板と脚の色。上に物を置く面は天板 |
| `foldingChair` | 形（パイプ椅子 ／ ミーティングチェア ／ スタッキングチェア）、**たたむ**（パイプ椅子：折りたたみ、ミーティング：座面を跳ね上げてネスティング）、**キャスター**の有無、ひじ掛け、背もたれ（樹脂 ／ メッシュ ／ クッション）、座面とフレームの色。たたんだ状態は奥行きが変わるので、当たり判定の本体も変える |
| `cardboardBox` | 幅・奥行き・高さ、**フタ**：閉じてテープ ／ 半開き ／ 全開（フラップの角度）、**フタの形式**：フラップ（段ボール）／ かぶせ蓋（お菓子・贈答の箱）／ なし（トレー）、**材質**：段ボール ／ 薄い紙箱、色（クラフトが既定。色を変えるとお菓子の箱にも）、**印刷**：なし ／ 取扱注意 ／ 引越し ／ 通販 ／ お菓子柄 ／ 帯。閉じていれば上に積める |
| `partition` | 幅・高さ、**面の材質**：布 ／ アクリル（透明・すりガラス）／ 木 ／ ホワイトボード、透明度、上だけ透明（上下で材質を分ける）、**フレーム**：アルミ ／ 木 ／ なし、**足**：T 字 ／ 平たい台 ／ キャスター、連結枚数、色 |
| `printer` | **種類**：家庭用インクジェット（複合機）／ A4 レーザー ／ オフィス複合機（床置き、トレイ段数）、色、スキャナーのフタの開閉、出てきた紙、操作パネル |
| `organizer`（小物入れ） | 幅・奥行き・高さ、**仕切り**（横 × 縦）、材質（プラスチック ／ 木 ／ アクリル ／ ワイヤー）、色、中身（なし ／ ペン ／ 文房具いろいろ） |
| `whiteboard`（脚付き） | 板の幅 900〜1800・高さ 600〜1200、両面、**キャスター付きの脚**、ペン置き、フレームの色、**書いてある内容**（なし ／ 会議メモ ／ 間取りの落書き）、板の傾き（回転式） |
| `wallClock`（壁掛け） | 直径、形（丸 ／ 四角 ／ 駅の時計）、枠の材質・色、文字盤（数字 ／ 線だけ）。**針が画面の時間帯スライダーの時刻を指す**と楽しい |

## 6. ブラッシュアップ（フェーズ 4）

| アセット | 直すところ |
|---|---|
| ドラム式洗濯機 | 前面を少し傾ける、扉はめっきの輪＋ふくらんだガラス＋中のドラムの穴、洗剤の引き出し、操作パネル（ダイヤル・表示・ボタン）、継ぎ目、足、上面のフタの線 |
| 姿見 | スタンド式を作り直す：**左右の支柱で鏡をはさみ、ノブで角度を変える**形と、**後ろに 1 本脚のイーゼル**形。傾きの角度をパラメータに。立てかけは壁に触れる位置を確かめる |
| ゴミ箱 | 壁に厚みのある空洞にする（中は暗い）、ゴミ袋のふち、ペダル式・スイングフタ・分別 2 段 |
| 全体 | 2 章の道具で全アセットを見直す。とくにソファ・ベッド・冷蔵庫・チェスト・テレビ台・椅子類。見直すたびに「前後」をギャラリーで撮って並べる |

## 7. フェーズと順番

| フェーズ | 内容 | 終わったら見るもの |
|---|---|---|
| 0 | 共通の道具（角・継ぎ目・金属・扉・引き出し・足・印刷）と、種類の変換の仕組み | 道具だけを並べた試作ページ、変換のテスト |
| 1 | 分割：モニター・ノート PC・キーボード・PC 本体・本・書類・ファイルボックス・電子レンジ・炊飯器・ケトル | ギャラリー、古い JSON がそのまま開けること |
| 2 | 棚の統一：`shelf` / `metalRack` / `cabinet`、プリセット | 本棚・カラーボックス・レンジ台・チェストが前と同じかそれ以上に見えること |
| 3 | 新規：オフィスデスク、椅子、段ボール、パーテーション、プリンター、小物入れ、ホワイトボード、壁掛け時計 | ギャラリー、オフィス系のテンプレート（例：「在宅ワーク 8 畳」「小さな事務所」） |
| 4 | ブラッシュアップ：洗濯機・姿見・ゴミ箱、全アセットの見直し | 前後の比較 |

各フェーズの終わりにテスト（重なり・動線・全アセットの端の値）、AI 向けガイドの再生成、テンプレートの見直しをして、コミットする。
アセットの数は 33 → 50 前後になる見込み。カタログが長くなるので、カテゴリのタブと検索はそのまま使える。

## 8. 決めたこと

- 棚はカタログ上 3 種類（オープン棚・メタルラック・扉付き）に分ける。作る道具は 1 つ。
- 中身は積み重ねだけで表現する。「おまかせで詰める」は作らない。
- 順番は 0 → 1 → 2 → 3 → 4。
