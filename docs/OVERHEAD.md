# 床から浮いている物（空中の家具）

ロフトベッド・壁の棚・吊り戸棚・天袋・天井の物干しのように、**床から離れたところに本体があって、下をくぐれる・下に物を置ける**物の扱い。
派生アプリ（装置レイアウト版）にも同じ仕組みを入れるので、考え方と移植の手順をここにまとめる。

## 1. 考え方

新しい置き方（`placement`）は作らない。
「浮いている」の正体は次の 2 つだけなので、いまある仕組みを少し広げる。

- 本体が床から離れた高さにある（壁の棚、天井の物干し）
- 本体がいくつかの箱に分かれていて、そのあいだが空いている（ロフトベッドの柱と床板）

もとから当たり判定（`overlaps3D`）は高さも見ている。だから、エアコンの下に机を置いてもぶつからない。
動線は、下端が 1200mm より上にある物を障害物にしない。
足りなかったのは次の 4 つ。

| 拡張 | 中身 | 使っているアセット |
|---|---|---|
| **`solids`** | 本体を複数の箱で表す。当たり判定・動線・「床に落とせない場所」は箱ごとに調べる | ロフトベッド（柱 4 本・床板・はしご）、スピーカーのペア（2 台のあいだにモニターを置ける） |
| **壁付けの面** | 壁付けでも `surfaces` を書けば、上に物を置ける。上の物は棚と一緒に動く | 壁付けの棚・吊り戸棚・天袋 |
| **`elevation` の関数** | 取り付け高さを、パラメータと部屋（天井高）から決められる | 天袋（天井にぴったり）、ポスター（中心が目の高さ） |
| **`blocks`** | 当たり判定と動線に入るかどうか。天井付けは既定で入らない（照明）。ラグ・カーテン・クッションは `false` | 天井の物干し（`true`）、ラグ・カーテン・クッション・間仕切りカーテン |

## 2. それぞれの仕組み

### 2.1 `solids`（`AssetDef.solids?(p): LocalBox[]`）

- アセットのローカル座標（mm、底面中心が原点）で、場所をとる箱を並べて返す。
- `body` を省略すると、全部の箱を囲む外形が `body` になる。吸い付き・選択の枠・ツールバーの位置は、いままでどおり外形を使う。
- 部屋の座標では、`itemFootprint2D` が返す `Footprint2D` に `parts` が付く。
  - `overlaps3D(a, b)` は、`parts` があれば箱どうしで調べる（外形が重なっていなければ、すぐに `false` を返す）。
  - 箱の一覧がほしいところでは `partsOf(f)` を使う（`parts` がなければ外形 1 つ）。
- 使っているところ：
  - `collisions`・`placeNewItem`：`overlaps3D` を通るので何もしなくてよい。
  - `solids()`（`pickAlongRay` の「埋まっている場所」）：箱ごとに出す。ロフトベッドの床板の下の床に、物を落とせる。
  - `analyzeFlow`：箱ごとに、下端が `HEADROOM`（1200）より下のものだけを障害物にする。床板が高ければ下を通れる。ミドルベッドでは通れない。ドア・クローゼット・掃き出し窓の判定も箱ごと。
  - 接地影：床に触れている箱ごとに小さな影を落とす。床板の下の床が暗くならない。

### 2.2 壁付けの面

- `itemSurfaces` は、壁付けの物を一律に外していた。いまは、**`surfaces` を書いた壁付けの物だけ**面を返す（書かなければ、いままでどおり何も置けない）。天井付けは返さない。
- 積み重ねの仕組み（`stacking.ts`）は面の持ち主の置き方を見ていない。だから、壁の棚の上の物は「載っている」と判定され、棚と一緒に動き、重なりにならない。
- 壁付けの物をドラッグするとき、上に載っている物を吸い付きの相手から外す（`EditLayer`）。外さないと、自分の荷物に吸い付いて、がたつく。

### 2.3 `elevation` の関数

- `elevation?: number | ((p, room: { height }) => number)`。
- 追加したときの高さは `wallElevation(type, params, room)`（`placement.ts`）で求める。あとからパラメータを変えても、高さは動かない（ふつうの壁付けと同じ）。
- AI 向けのカタログでは、天井高 2400 のときの値に「（大きさや天井高で変わる）」を添えて出す。

### 2.4 `blocks`

- `isPassive(type)` は `!(asset.blocks ?? asset.placement !== 'ceiling')`。
- いままでコードに書いていた「ぶつからない種類」の一覧（`rug` / `curtain` / `cushion`）は、各アセットの `blocks: false` に移した。
- 天井付けで `blocks: true` の物は、追加するときも空いている場所を探す。

### 3.2 確かめること

- `npm test`：`overhead.test.ts` のテスト。
  - 壁の棚に載った物が、棚と一緒に動く。
  - 浮いている物の下の家具とはぶつからない。同じ高さにある背の高い家具とはぶつかる。
  - ロフトベッドの床板の下にデスクを置いても重ならず、柱には重なる。
  - 床板の下の床に物を落とせる。
  - 動線は、高い床板の下を通れて、ミドルの下は通れない。
  - 天井の物干しは、机とはぶつからず、背の高い本棚とはぶつかる。
  - スピーカーのペアのあいだのモニターは重ならない。
- テンプレートの重なり・動線のテスト（ロフトベッドの部屋 `loft-6`）。
- ブラウザでの確認：
  - 壁の棚をドラッグすると、上の物がついてくる。
  - ロフトベッドの下へデスクをドラッグできて、重なりの赤い枠が出ない。
  - 天袋を追加すると、天井にぴったり付く。

### 3.3 派生アプリで考えること

- `HEADROOM`（1200）は「人がかがまずに通れる高さ」ではなく、「下端がこれより上なら通路の邪魔にならない」という目安。装置のレイアウトで、台車やフォークリフトが通るかを見るなら、別の値にするか、動線ごとに変える。
- 箱の数が多いアセット（たくさんの棚・柱）は、当たり判定の組み合わせが増える。いまは外形が重ならなければすぐに打ち切るので、1 アセットに 10 個くらいまでなら気にしなくてよい。
